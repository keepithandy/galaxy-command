# Manual Smoke Pass

Use this after a small Galaxy Command UI or flow patch.

1. Load the galaxy view and select at least two different planets.
2. Confirm selected, available, and unavailable states remain visually distinct.
3. Trigger one normal movement or conquest flow without changing balance values.
4. Verify status/resource panels update consistently with the action.
5. Reload once and confirm persistent campaign state remains intact.
6. Check the galaxy view at a narrow mobile width for clipped or unreachable controls.

Run focused automated checks as well when turn, combat, or persistence logic changes.
